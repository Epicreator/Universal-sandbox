# Universal Sandbox

An interactive solar system sandbox made with HTML5 Canvas, CSS and plain JavaScript (no libraries).

- Sun + Mercury, Venus, Earth, Mars, Jupiter, Saturn with Kepler-correct orbital speeds
- Spawn planets, meteors, comets, stars and black holes anywhere and watch gravity react
- Tap = drop into a circular orbit, drag = launch with your own speed (dotted line previews the path)
- Pause, slower / speed up (0.25x - 32x), add random planet, trails, names, clear, reset
- Works on phones and desktops: pinch / scroll to zoom, drag to pan

## Run locally
Open `index.html` in any browser.

## Publish on GitHub Pages
1. Upload `index.html` and `.github/workflows/pages.yml` to your repo (branch `main`).
2. Repo **Settings -> Pages -> Build and deployment -> Source: GitHub Actions**.
3. Push (or run the workflow from the **Actions** tab). Your game goes live at `https://<username>.github.io/<repo>/`.
